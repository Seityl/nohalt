# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and ideas rather than people, and keep discussion on topic. Harassment, personal attacks and publishing others' private information are not tolerated.

## Enforcement

Report unacceptable behaviour privately to the maintainers through a [private security advisory](https://github.com/Seityl/nohalt/security/advisories/new) (it is the one private channel GitHub offers on every repository), marked "Code of conduct". Reports are handled confidentially. Maintainers may remove comments, commits and contributions, and may ban contributors temporarily or permanently, in line with the Contributor Covenant's enforcement guidelines.
